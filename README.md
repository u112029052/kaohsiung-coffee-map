# 港都咖啡散策｜高雄地區咖啡廳分布誌

這是一個結合 **LLM Wiki 知識庫工作流** 與 **純靜態網頁設計** 的高雄咖啡廳分布整理專案，並透過 `AGENTS.md` 規範 AI 代理人進行資料萃取、知識庫維護與網頁自動擴充。

## 目前收錄範圍
- **新興區 (`districts/xinxing.html`)**：鹿聊 Lu liao、一盞咖啡
- **苓雅區 (`districts/lingya.html`)**：覓心手沖咖啡

## 部署至 GitHub Pages
1. 將整個專案資料夾推送至 GitHub Repository。
2. 進入 Repository 的 **Settings → Pages**。
3. 在 **Source** 選擇 `Deploy from a branch`，Branch 選擇 `main` / `/ (root)` 並儲存，即可獲得線上瀏覽網址。
